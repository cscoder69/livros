# Exemplos do capítulo 5

Exemplos didáticos preparados para comparar implementações. Contêm falhas intencionais; não substituem a solução do capítulo 4.

## Arquivos

- `comparacao.ipynb`: arquivo de código independente com definições, comparações e demonstrações. Não requer os arquivos do capítulo anterior.
- `propostas.py`: as mesmas funções, para executar com Python 3 no computador.
- `verificar.py`: verificações automáticas dos comportamentos, incluindo os erros intencionais.
- `gabarito.md`: interpretação dos resultados.

## **[COLAB]** Execução no navegador

No [Google Colab](https://colab.research.google.com/), use a opção para enviar um arquivo do computador e selecione `comparacao.ipynb`. Execute as células em ordem. Não requer bibliotecas externas nem chave de API. Depois de modificar uma definição, execute sua célula e os exemplos seguintes novamente. Para uma execução limpa, reinicie a sessão e execute tudo em ordem. Salve ou baixe seu arquivo de código modificado.

Os cenários reconstroem suas listas a cada execução. Na tabela, cada entrada é observada separadamente a partir de uma tarefa existente; portanto, as quantidades não se acumulam entre as linhas.

## **[COMPUTADOR]** Execução local opcional

Na pasta destes arquivos:

```text
python propostas.py
python verificar.py
```
