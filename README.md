# Materiais dos livros de Claudio Santos

Este repositório reúne os arquivos de código e materiais de apoio dos livros. Cada título tem sua própria pasta, com instruções de uso e a correspondência entre capítulos e arquivos.

## Livros disponíveis

- [SEM MEDO de programar com IA](sem-medo-de-programar-com-ia/README.md): exercícios, soluções de referência, testes e roteiros de apoio.

## Como começar

Abra a pasta do livro e leia o arquivo README.md, que apresenta as instruções iniciais. Para baixar os materiais, use **Code → Download ZIP** na página inicial deste repositório, extraia o arquivo no computador e abra a pasta do título desejado. O download inclui o conteúdo do repositório.

As informações de versão e de licença ficam na pasta de cada livro. Os materiais de apoio não incluem o texto integral dos livros.
